## Limits I found

- The fact check needs the word "gpa" in the post. A post that says "grade point average" would be sent to review. This is safe but adds work for the officer.
- The fact check only removes values. If the LLM leaves out a branch or a backlog rule that the post states, Python does not add it back. The placement officer's check covers this.
- The test suite uses a fake LLM, so it does not measure how good a real model is. The `live` test and the officer's check cover that gap.
- `summary.txt` lists students "eligible for no job yet" using matched posts only. Posts still in review can make that list look longer than it should, so the file now says which posts are in review.

## My rule for AI help

I use AI to help write and fix code, but I do not keep a line I cannot explain. For each function above I can say what it does, why it is there and what test covers it.
